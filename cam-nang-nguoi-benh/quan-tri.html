🔐 Quản trị Thư viện GDSK

Dành cho cán bộ được phân quyền cập nhật nội dung. Đăng nhập bằng khóa truy cập (token) của kho dữ liệu.

Chưa có khóa truy cập? Cách tạo (làm 1 lần)
  1. Đăng nhập GitHub bằng tài khoản chủ kho dữ liệu → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: chọn Only select repositories → chọn kho của Thư viện.
  3. Permissions → Repository permissions → Contents: chọn Read and write. Không cần quyền nào khác.
  4. Chọn thời hạn (ví dụ 90 ngày), bấm Generate token, sao chép chuỗi bắt đầu bằng github_pat_ và dán vào ô bên dưới.

Mỗi cán bộ nên dùng token riêng; thu hồi token là thu hồi quyền quản trị ngay lập tức.
